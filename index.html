Joga Bonito ↗

Live Next.js FastAPI scikit-learn

A World Cup 2026 prediction engine — full 48-team bracket simulation, individual match predictions, squad exploration.

The classifier is a scikit-learn histogram gradient-boosting model trained on 49,214 international matches with four-year half-life time decay, emitting Poisson scoring rates rather than a bare win probability. An 18-feature squad-quality layer — squad value, elite-league share, tactical entropy, star-reliance measured as a Gini coefficient — is applied at inference rather than during training, because historical squad data simply doesn’t reach back far enough to learn from. Dixon-Coles calibration corrects the low-scoring outcomes Poisson gets wrong, and neutral-ground symmetrisation strips home-team bias by averaging each prediction with its reverse. Brackets resolve through 10,000 Monte Carlo simulations.

  • 49,214matches trained on
  • 20player archetypes
  • 10,000bracket simulations

Valedictorian Run ↗

Live Next.js 16 TypeScript Supabase

A study platform that turns course PDFs into topic wikis, spaced-repetition cards, mock exams, teach-back grading and grounded Q&A with page-level citations.

It has no vector database, on purpose. The model reads each uploaded file once at ingest, extracting page-cited chunks and building a topic index; the corpus then stays in context at query time, with Postgres tsvector ranking as a fallback only when the window overflows. For a bounded personal corpus that removes retrieval drift and relevance tuning entirely. Figures are pulled out with mupdf, rasterised with sharp and linked back to topics, so the chat can read a diagram and still cite the page it came from.

  • Page-levelcitations on every answer
  • No vector DBcompile-on-ingest instead
  • $0monthly running cost

Experience

Data Science (NLP) Intern

Ministry of Defence, Singapore May — Jul 2026

Built a nine-stage pipeline over 2.1GB of compressed Reddit archives, taking 13.6M raw records down to 737K semantically chunked units and clustering them — UMAP to five dimensions, then HDBSCAN, then c-TF-IDF — into a 359-topic taxonomy I rolled up by hand into 17 macro topics.

Fine-tuned SingBERT, a Singapore-specific model that survives Singlish and code-switching, for sentiment classification. Evaluated against a 217-row human-annotated gold set it reached 84% accuracy at κ = 0.71 and macro F1 0.78, beating VADER (κ = 0.31), generic BERT (κ = 0.52) and zero-shot GPT-4.1-mini (κ = 0.68). A separate four-stage cascade classified commitment along two axes against a 727-row gold set.

Shipped a seven-page Streamlit dashboard and a retrieval chatbot over a FAISS index of all 737K chunk embeddings. A rule-based query router — no model call, under five milliseconds — decides whether a question is quantitative, and if it is, answers from a pre-aggregated fact table in under 100ms rather than paying for an LLM round trip.

  • 13.6M → 737Krecords structured
  • κ = 0.71vs. human gold set
  • <100msrouted query latency

About

Most of what I enjoy about this work happens after the model trains. Anyone can report an accuracy figure; the interesting question is what it was measured against, and whether a simpler baseline would have done just as well. That habit is why the MINDEF classifier was benchmarked against three alternatives on annotated data instead of a held-out split, and why Valedictorian Run has no vector database — I couldn’t justify one for a corpus that fits in context.
